# TreeLab – Binary Tree Traversal Explorer

An interactive web application for learning and visualizing binary tree traversal algorithms.

## Live Demo

[Visit TreeLab Website](https://treelabbinarytreetraversal.vercel.app/)

## Project Overview

TreeLab demonstrates how nodes in a binary tree are visited using four traversal algorithms. It provides visual highlighting, step-by-step execution, a traversal sequence, and a trace table.

## Technologies Used

- HTML
- CSS
- JavaScript
- SVG

## Features

- Binary tree visualization
- Preorder traversal
- Inorder traversal
- Postorder traversal
- Level-order traversal
- Play, Pause, Step, and Reset controls
- Traversal progress indicator
- Step-by-step trace table
- Queue visualization
- Time and space complexity comparison

## Traversal Sequences

| Algorithm | Visit Order |
|---|---|
| Preorder | A → B → D → E → C → F → G |
| Inorder | D → B → E → A → F → C → G |
| Postorder | D → E → B → F → G → C → A |
| Level-order | A → B → C → D → E → F → G |

## How to Run

1. Open or download this repository.
2. Open `treelab_binary_tree_traversal.html` in a web browser.
3. Select a traversal algorithm.
4. Use Step or Play to explore the traversal.
