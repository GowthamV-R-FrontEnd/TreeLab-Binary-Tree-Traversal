02 · Traversal logic

The order changes, but each method visits all seven nodes exactly once.

PreorderRoot → Left → Right

Useful for copying or serializing a tree.

InorderLeft → Root → Right

Gives sorted order in a binary search tree.

PostorderLeft → Right → Root

Useful when deleting or evaluating a tree.

Level-order (BFS)Visit level by level using a queue (FIFO)

Useful when processing nodes by depth.

05 · Complexity comparison

For n nodes, all four traversals take linear time because each node is processed once.

Key: n = number of nodes, h = tree height, w = maximum width. Recursive DFS uses the call stack; level-order uses a queue. In the worst case, auxiliary space can be O(n).

if node is null: return
inorder(node.left)
visit(node)

Recursive postorderpostorder(node):
if node is null: return
postorder(node.left)
postorder(node.right)
visit(node)
Iterative level-order Create an empty queue, enqueue the root. While the queue is not empty: dequeue a node, visit it, then enqueue its left child and right child if they exist.
